## 每期最值得记住的一件事

- **01｜先拆骨架，再调颜色。** 页面先还原成几个矩形，找到唯一重复单元，CSS 才不会越写越散。
- **02｜数据对不上，视觉再像也不算完成。** 6 只基金、合计、占比、涨跌必须逐项自洽；复刻的是界面，不是投资建议。
- **03｜完整性靠清单，不靠印象。** 7 个日期组的条目数相加必须等于 24；少一篇，“一周盘点”就失去意义。
- **04｜底图、轨迹、站点必须共用一套投影。** 轨迹解码用终点误差验证，移动端用安全区约束标签与弹窗。
- **05｜显示 Seed 不等于能复现。** 只有把噪声置换和粒子随机流都交给 seeded PRNG，同 Seed 才能得到同一幅画。

## 按案例类型复用

### 信息流 / 仪表盘（Case 01）

- 固定终端栏 + 网格/光晕背景 + 渐变标题。
- 4 张 KPI：总数、窗口、分类数、分布环图。
- 一种情报卡片，左侧 3px 强调条，悬停上浮 2px。
- 数字滚动 1.1s，卡片入场 0.48s、错峰 28ms。
- 断点 900 / 560；900 以下导航隐藏，560 以下卡片单列。

### 报告 / 表格 / 双语（Case 02）

- 先找 iframe 真身，再拆 5 个模块。
- 语义表格保留表头关联；合计行必须校验。
- 560px 以下表格转卡片，字段一个不丢。
- 语言切换更新 `?lang=`、`document.title`、所有文案与 `html lang`。
- 打印隐藏浮动操作，保留免责声明与数据日期。

### 时间线 / 高密度内容（Case 03）

- 先做 24/7/9+ 清单，再开始排版。
- 日期在左、论文在右，圆点串联同一天。
- 卡片入场以“内容本来就在”为前提；隐藏只在 JS 主动授权后生效。
- 无 JS、减弱动效、打印三种场景都要可见。
- 原页面窄屏圆点 bug 要修，并写进文章。
- 相对时间（“22 小时前”）发布后会过期；复刻时冻结为绝对日期，并标注快照时间。

### 地图 / 轨迹（Case 04）

- 行程数据放在内联 JSON，先核对 3 个日程、12 站、9 段轨迹。
- 轨迹增量解码后，用终点误差验证；首点是“纬度、经度”，之后每对是“经度增量、纬度增量”，单位 `1e-6` 度。
- 77 张 z14 OSM 瓦片拼成底图，再压成 WebP 内嵌；运行时零外部请求。
- 桌面左面板 → 820px 以下底部抽屉。
- 安全区约束标签与弹窗；键盘支持 `Escape`、`+/-/0`。
- 验收看站点是否在安全区、标签是否遮挡、拖拽后是否露底。
- 必须保留 `© OpenStreetMap contributors` 与 ODbL 说明。

### Canvas / 生成艺术（Case 05）

- 5000 粒子、8 色日落板、Perlin 噪声、每帧 0.0015 淡出。
- 0.0015 的半衰期约 462 帧；60Hz 下约 7.7s，120Hz 下约 3.85s，以像素采样实测为准。
- Seed 必须同时固定噪声置换与粒子随机流。
- `resize` 用快照 + 坐标缩放，不重新生成。
- DPR 2、暂停、PNG 导出、减弱动效静帧、移动端重排。
- 验收：同 Seed + 同视口 + 同 DPR + 同 resize 历史 + 同帧数，像素哈希一致；换 Seed 即不同。
